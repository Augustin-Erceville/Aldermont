# Rank Icons
 
Ce dépôt héberge les icônes de rang utilisées par les cartes de la commande `/rank` d'un bot Discord.
 
Il est public **uniquement** pour que le bot puisse charger les images via leurs liens directs. Ce n'est pas une bibliothèque de ressources libres.
